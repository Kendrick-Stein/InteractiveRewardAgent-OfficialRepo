Use the code

IRA can be used as an evaluator over a replayed desktop state, or through the bundled parallel sample replay runner.

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

The host project must provide compatible desktop_env APIs. This repository does not vendor the full desktop environment runtime. For the Docker-based desktop simulator and OSWorld-style setup, see Computer-use-agents/GUI-Docker-Env.

Parallel sample replay

The migrated replay runner reads one YAML file, launches compatible desktop environments, replays task trajectories, optionally asks IRA to score the final state, and writes summary files under the configured run directory.

python -m ira_replay.parallel_sample_replay \
  --config configs/parallel_sample_replay.yaml \
  --dry-run

python -m ira_replay.parallel_sample_replay \
  --config configs/parallel_sample_replay.yaml

Default behavior

The sample config selects one Chrome task, uses one worker, writes to runs/parallel_sample_replay, and starts with reward_agent.enabled: false so the desktop environment path can be tested before model scoring.

Replay configuration

desktop_env:
  provider_name: docker_server
  base_url: http://127.0.0.1:50003
  token: reward

tasks:
  examples_dir: rewardbench_examples
  categories: [chrome]
  max_tasks_per_category: 1

replay:
  output_dir: runs/parallel_sample_replay
  max_workers: 1

reward_agent:
  enabled: false
  model_id: gpt-4o
  tool_app: auto

Using IRA directly

When a desktop environment is already reset or replayed to the final state, instantiate the evaluator and call evaluate.

from RewardAgent.agent_improved import RewardAgentImproved

agent = RewardAgentImproved(
    model_id="gpt-4o",
    env=env,
    app="all",
    max_images=5,
    max_steps=30,
)

result = agent.evaluate(
    task_instruction="Check whether the requested GUI task is complete.",
    apps=["chrome"],
    output_dir="runs/reward_agent_eval",
)
